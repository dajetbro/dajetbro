# Dajet

**Silence, styled.** — the official account of the Dajet browser: a quiet browser for macOS.

**🌐 Versions:** [English](README.md) · [Русский](README.ru.md)

## The project

Dajet is a browser that stays silent. A dark start page, one input line, local history, no telemetry.

- **The browser:** [dajetbro/dajet-browser](https://github.com/dajetbro/dajet-browser)
- **Site & download:** [dajet.ru/browser](https://dajet.ru/browser) · [bro.dajet.ru](https://bro.dajet.ru)
- **The studio:** [dajet.ru](https://dajet.ru)

## Principle

Its start screen makes zero network requests: widgets run entirely on your Mac — calendar, reminders, battery, media, time. No telemetry, no accounts, no cloud. Themes are published design works by the Dajet design studio.
