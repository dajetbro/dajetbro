# Dajet

**Official account of the Dajet browser** — a quiet browser for macOS.

Silent to the network. Loud in style. Its start screen makes zero network requests: widgets run entirely on your Mac — calendar, reminders, battery, media, time. No telemetry, no accounts, no cloud. Themes are published design works by the [Dajet design studio](https://dajet.ru).

- 🌐 Site & download: [dajet.ru/browser](https://dajet.ru/browser)
- 🦉 The browser: [dajetbro/dajet-browser](https://github.com/dajetbro/dajet-browser)
- ✍️ Студия (по-русски): [dajet.ru](https://dajet.ru)
