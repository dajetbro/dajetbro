# Dajet

**Молчит в сеть. Говорит стилем.** — официальный аккаунт браузера Dajet: тихого браузера для macOS.

**🌐 Версии:** [English](README.md) · **Русский**

## Проект

Dajet — браузер, который молчит. Тёмный стартовый экран, одна строка ввода, локальная история, никакой телеметрии.

- **Браузер:** [dajetbro/dajet-browser](https://github.com/dajetbro/dajet-browser)
- **Сайт и скачивание:** [dajet.ru/browser](https://dajet.ru/browser) · [bro.dajet.ru](https://bro.dajet.ru)
- **Студия:** [dajet.ru](https://dajet.ru)

## Принцип

Стартовый экран делает ноль сетевых запросов: виджеты работают целиком на твоём Mac — календарь, напоминания, батарея, медиа, время. Никакой телеметрии, аккаунтов и облака. Темы — публикуемые дизайн-работы [студии Dajet](https://dajet.ru).
